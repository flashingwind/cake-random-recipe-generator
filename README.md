# ケーキランダムレシピジェネレーター

パウンド・スポンジ・シフォンなどのケーキのレシピは、パラメータ空間では連続しているのではないか、という仮説の実験道具です。

## 使い方

`index.html` をブラウザで開くだけで動きます（静的サイト）。GitHub Pages で公開する場合は、このリポジトリの Settings → Pages で main ブランチを選んでください。

- **ランダム生成**：既存のケーキ（アンカー）を2つ選び、配合をランダムに補間します
- **手動指定**：スライダーでパラメータを動かすと、成立判定とレシピが連動します
- **成立判定**：膨らみ・水分・乳化・砂糖などの観点から、理由つきで目安を出します
- **パラメータ空間プロット**：立て方ごとにグラフを分け、領域を「一番近い既存ケーキ」で塗り分けます

## 設計メモ

- パラメータはすべて「小麦粉100gあたり」で表す（ベーカーズパーセント）
- 油脂は **純脂肪のグラム数** で数える。バターは重量×0.83、水分を含む素材としては別枠で数える
- グラフの横軸は二重目盛り：下が純脂肪、上はバター換算（計算尺の発想）
- 非連続な変数（立て方：クリーミング／共立て／別立て）は軸に入れず、グラフ自体を分ける
- アンカーはネットの定番レシピから換算した概算値。増やすほど領域の解像度が上がる
- ※ ジェノワーズとカステラの卵量は、ネットの定番レシピの範囲（ジェノワーズ：粉100あたり卵167〜200g、カステラ：同200〜260g）に合わせて調整済み（2026-11-09確認）

## 今後の課題

- アンカー（既存レシピ）を増やして領域塗り分けの解像度を上げる
- 成立判定のルールの精度を、実際に焼いた結果で検証する
- 焼き上がりの記録（写真・感想）をパラメータと紐づけて残す
