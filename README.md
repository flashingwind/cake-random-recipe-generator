# ケーキランダムレシピジェネレーター

パウンド・スポンジ・シフォンなどのケーキのレシピは、パラメータ空間では連続しているのではないか、という仮説の実験道具です。

## 使い方

`index.html` をブラウザで開くだけで動きます（静的サイト）。GitHub Pages で公開する場合は、このリポジトリの Settings → Pages で main ブランチを選んでください。

- **ランダム生成**：既存のケーキ（アンカー）を2つ選び、配合をランダムに補間します
- **手動指定**：スライダーでパラメータを動かすと、成立判定とレシピが連動します
- **成立判定**：膨らみ・水分・乳化・砂糖などの観点から、理由つきで目安を出します
- **パラメータ空間プロット**：立て方ごとにグラフを分け、公開レシピを使った重み付きk-NNの分類結果で領域を塗り分けます

## 設計メモ

- パラメータはすべて「小麦粉100gあたり」で表す（ベーカーズパーセント）
- 油脂は **純脂肪のグラム数** で数える。バターは重量×0.83、水分を含む素材としては別枠で数える
- グラフの横軸は二重目盛り：下が純脂肪、上はバター換算（計算尺の発想）
- 非連続な変数（立て方：クリーミング／共立て／別立て）は軸に入れず、グラフ自体を分ける
- アンカーはネットの定番レシピから換算した概算値。増やすほど領域の解像度が上がる
- ※ ジェノワーズとカステラの卵量は、ネットの定番レシピの範囲（ジェノワーズ：粉100あたり卵167〜200g、カステラ：同200〜260g）に合わせて調整済み（2026-11-09確認）

- `data/recipes.json`：実レシピの換算データ（ホットケーキ14件・クレープ15件、出典URLつき）。「混ぜるだけ」グラフに点として表示している

## 今後の課題

- アンカー（既存レシピ）を増やして領域塗り分けの解像度を上げる
- 成立判定のルールの精度を、実際に焼いた結果で検証する
- 焼き上がりの記録（写真・感想）をパラメータと紐づけて残す

## 現在の学習モデルと領域表示

領域分類は元のモデル方式に戻し、標準化＋RBF SVM（C=2、gamma=scale）＋3分割の確率校正を使います。特徴は脂肪・卵・追加液体量の3項目です。近傍投票や距離の閾値は領域分類・領域の切り落としに使いません。元の5項目版とモデル方式は同じですが、特徴を3項目にしたため再学習しています。

現在は実レシピ84件のうち重複1件を除く83件と、アンカー11件の計94件で最終学習しています。`python3 ml/train_continuous.py` で再現できます（numpy・scikit-learnを使用）。実レシピだけを出典ホスト単位で除外した交差検証は73/83件正解でした。アンカーは評価に混ぜません。従来のk-NNの生成・評価スクリプトは比較資料として残していますが、画面の領域分類には使っていません。

`data/svm-field.js` は全7カテゴリの確率を持つ3D格子です。格子間は三線形補間し、カテゴリへの連続的な近さを色に反映します。通常は94件全体の凸包内に表示を限定します。これは表示範囲だけの制限で、SVMの推定値は変更しません。「データ範囲外への推定も表示」をオンにすると従来の全描画範囲への外挿が見えます。範囲内も未観測の配合を含むため、領域のつながりは焼き上がりの成立を実証するものではありません。

## パウンド・シフォン・ジェノワーズの関係

既定は全7カテゴリの表示です。チェックで3種類に絞ると、同じ全7分類SVMの出力を選択した3種類内で正規化して見せます。3種で別のモデルを学習しているわけではありません。チェックを外すと全7カテゴリを表示します。他カテゴリが優勢な場所を除いて3種のスコアが最も近い格子付近の配合と割合を表示しますが、これはモデル上の候補であり、実際のケーキの混合率ではありません。

3Dは半透明の領域とカテゴリ名が主表示です。実レシピは小さい確認用の点で重ね、重心は表示しません。家庭用は薄く、標準的は濃く表示します。異なる立て方のカテゴリ間では斜線を入れません。分類の支持領域を距離閾値で切り落として人工的な空白を作る処理は廃止しています。

## 2Dは3D領域の投影

2Dは別の分類器で再分類せず、実際に塗った3D格子を水分方向に重ねた投影です。水分0g固定の断面ではありません。同じ立て方の複数カテゴリが投影で重なる場合だけ斜線にします。投影上の重なりと、3Dの同じ位置での拮抗は区別します。

水分スライダーは1個だけで、生成レシピと★の位置を調整します。3D・2Dの領域は水分スライダーで絞り込みません。ドラッグ／矢印キーで回転し、プラス／マイナスで拡大縮小できます。スマホでは説明文15px、軸文字14〜16pxを保って画面幅に合わせて描画します。

## データ追加

2026-11-13に、みんなのきょうの料理からパウンド2件・ジェノワーズ2件・シフォン3件を追加しました。出典、材料量、換算の仮定、取得原文のハッシュを各レシピの `review` に残しています。型用・仕上げ用の油脂やシロップは除外しています。全卵50g、卵黄20g、卵白30g、油0.92g/mlなどの重量換算は仮定です。追加液体量は材料全体の総水分ではありません。変形レシピ、量が不明なもの、未定量のペーストなどが多いものは無理に取り込んでいません。

原データ追加後は `node scripts/train-classifier.cjs` で点のデータと比較用k-NN資料を更新し、`python3 ml/train_continuous.py` で表示用SVMを再学習します。`data/collection-additions-2026-11-13.json` が今回の追加記録です。新しい計算上の配合を実レシピとして混ぜていません。

検証：`node --test tests/*.test.cjs`。モデル上の連続性と実際の焼成結果は別途検証が必要です。JSには内容ハッシュ付きURLを使い、古い描画コードのキャッシュが残りにくくしています。

クレープなどの領域がデータのない空間まで広がって見えないよう、通常表示は全学習点の凸包内に限定しています。カテゴリ別の支持距離で切り落とす処理には戻していません。格子の中心が凸包内かどうかで判定する近似です。
